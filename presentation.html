OOP & DESIGN PATTERNS
OOP Hierarchy & Design Patterns
Inheritance & Polymorphism

Abstract base class Transaction extended by CreditCardTransaction (CVV, card network, zip) and WireTransaction (SWIFT, account, destination bank).

Factory Pattern (EngineFactory)

Dynamically instantiates and hot-swaps between RULE_BASED, ML_ANOMALY, and HYBRID engines without application restarts.

Custom Exception Hierarchy

FraudDetectionException specialized by DatabaseException and ThresholdOutOfBoundsException for strict validation.

Generic DAO Architecture

GenericDAO<T, ID> provides standardized CRUD operations for User, Transaction, SystemConfig, and FraudAlert entities.

DETECTION ENGINES
Dual-Model Detection: Heuristics vs ML Anomaly

Rule-Based Engine

  • Velocity Check: Flags rapid-fire payments exceeding configured time-window limits.
  • Geographic Filter: Identifies high-risk sanctions destinations (FATF/OFAC).
  • Spending Limit: Flags high-amount deviations exceeding thresholds.
  • Rail Validation: CVV match check and SWIFT identifier syntax tests.

AI ML Anomaly Engine

  • Multivariate Features: Amount ratio sigmoid, velocity density, geo entropy, and device fingerprint risk.
  • Dynamic Weights: Admins dynamically tune feature weights live from the UI.
  • Isolation Scoring: Amplifies risk when compound correlations appear.
  • Explainable AI: Generates transparent feature breakdown weights.
CONCURRENCY & MULTITHREADING
Asynchronous Pipeline & Thread-Safety
Producer-Consumer

Bounded LinkedBlockingQueue<Transaction> absorbs traffic surges with backpressure protection. Daemon workers process evaluations asynchronously.

Thread-Safe Collections

ConcurrentHashMap and CopyOnWriteArrayList deliver lock-free sliding-window velocity checks without database contention.

Atomic Telemetry

AtomicInteger and DoubleAdder track total volume, processed transactions, and precision metrics without lock degradation.

DATABASE & PERSISTENCE
Pure JDBC Pooling & Manual ACID Transactions

Custom DBConnectionPool

Zero third-party pooling overhead. Features automatic health checks via connection.isValid(2), connection leak recovery, and schema auto-creation on first launch.

Manual Transaction Boundaries

Enforces connection.setAutoCommit(false), executing atomic multi-table inserts (Transaction + FraudAlert) with explicit commit() and rollback in catch blocks.
